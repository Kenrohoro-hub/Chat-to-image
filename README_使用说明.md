# Chat to image 使用说明

[English](README_User_Guide.en.md) · [下载最新版](https://github.com/Kenrohoro-hub/Chat-to-image/releases/latest)

## 下载与启动

Windows 10（1809 起）或 Windows 11 x64 用户，下载 `Chat-to-image-版本号-windows-x64-setup.exe`，双击安装，从开始菜单打开 **Chat to image**。无需另装 Python 或 Node。

安装器使用自签证书，Windows 可能仍显示发布者提示。请从项目发布页下载。GitHub 的 **Source code** 是源码包，启动方法见 [项目首页](README.md#从源码启动)。

## 首次配置与第一张图片

需要自行准备 API 地址、Key 和模型；生成与对话会使用你配置的服务并产生相应费用。

1. 打开 **设置与 API → API 配置 → 生图API配置卡**，点击 **添加 API 配置**。
2. 填写服务地址和 Key，点击 **获取模型** 后选择图像模型；也可手动填写模型 ID。
3. 启用该配置、设为主用，点击 **保存配置**。
4. 回到 **创作**，在 **生图参数** 中选择模型、尺寸和张数。
5. 输入提示词，点击 **直接生成**。结果可下载、收藏或继续修改。

想通过聊天创作，再到 **对话API配置卡** 添加支持 **Responses** 的对话服务并保存。回到创作页选择对话模型，输入要求后点击 **发送**；明确要求生成或修改图片时，会调用图像服务。

## 常用操作

| 想做什么 | 操作 |
| --- | --- |
| 只优化文字 | 点击 **只优化提示词**；满意后点击回复下的 **按此提示词生图**。 |
| 使用参考图 | 上传、拖入或粘贴图片，说明每张图的用途；可用 `@` 指定图片。 |
| 修改已有图片 | 选中结果，点击 **继续修改**；局部修改用 **蒙版编辑**，标记区域并保存后再提交。 |
| 使用提示词库 | 选择条目后点击 **引用提示词**、**引用图片** 或 **引用提示词和图片**，检查草稿后再生成。 |
| 保存自己的提示词 | 在 **提示词库 → 个人提示词** 新建或保存当前草稿；通过 **管理分类** 整理。 |
| 找回作品和对话 | 从 **最近生成** 查看作品，从 **对话历史** 查看聊天；常用作品可加入收藏。 |
| 切换中英文 | 在 **设置与 API → 语言** 选择语言，再点击 **保存配置**。切换前先完成或停止任务，并保存草稿。 |

图片理解、联网、透明背景和编辑效果取决于模型支持。遇到超时或断线，先查服务商记录再重试；点击停止不保证远端取消或退款。

## 模型与备用服务

图像和对话配置分别管理，修改后需保存。需要备用时添加其他配置、调整顺序并开启 **自动切换备用**；只在明确拒绝或配置缺失等情况下切换，超时或结果不明时不会自动重发。

## 数据保存与备份

在 **设置与 API → 数据管理** 选择范围后导出 ZIP，恢复时选择 **从 ZIP 导入所选数据**。较大备份会分片，确认全部下载完成，导入时一次选齐同批次分片。

- **包含配置的备份含未加密 API Key，不要公开分享。**
- 作品备份不含全部网络提示词目录和预载图片。使用自定义提示词保存位置时，另行复制整个 `提示词库` 文件夹。
- 桌面和不同浏览器的作品、对话分别保存；切换入口后找不到历史时，回原入口导出再导入。

## 更新与换电脑

更新前备份重要数据，关闭程序，运行新版安装器并选择原安装目录。升级保留个人数据；卸载也不会自动清除使用后产生的配置和作品。

换电脑时重新安装、填写 API Key，再导入备份。不要靠复制旧 `user-config/` 迁移密钥，其加密内容绑定原 Windows 账户。

## 其他入口

- **本地浏览器**：运行安装目录的 `run-sync.cmd`。需要方便停服时运行 `run-sync.cmd --stay-open`，按 Ctrl+C 停止该入口创建的服务。
- **外部 Agent**：在 **设置与 API → Agent 连接** 中连接，重新打开 Agent 会话。命令行参数见 [CLI 说明](docs/codex-image-interface.md)。
- **遇到问题**：先查看界面错误提示；反馈到 [GitHub Issues](https://github.com/Kenrohoro-hub/Chat-to-image/issues) 时附版本、操作步骤和脱敏截图，不附 Key 或配置备份。
