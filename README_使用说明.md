# Chat to image 使用说明

[English User Guide](README_User_Guide.en.md) · [English README](README.en.md)

Chat to image 是在 Windows 本机运行的 AI 图片生成与编辑工具，支持直接生图、对话创作、参考图与蒙版编辑、提示词管理和作品备份。

当前版本 **0.2.0**。你需要自行准备可用的 API 地址、Key 和模型；本工具不附带模型服务或调用额度。生成图片和对话时，相应提示词、消息及参考图会发送给你配置的服务商。界面默认跟随系统语言：中文系统显示中文，其他系统语言显示英文。桌面版读取 Windows 系统 UI 语言，本地浏览器版读取浏览器首选语言。可在“设置与 API → 语言”选择“跟随系统 / 中文 / English”；此设置与欢迎页共用当前入口的语言偏好。选择后点击“保存配置”才会保存全部设置草稿并应用语言、刷新界面；取消或关闭不保存语言更改。生成或对话任务运行时不能切换，需先完成或停止任务。若关闭“重启后恢复输入框”且还有草稿，请先保存或清空草稿，或开启输入恢复。恢复“跟随系统”会清除手动选择。

## 下载与启动

### 从源码运行前需要什么

| 环境 | 说明 |
| --- | --- |
| Windows 与 WebView2 | 桌面窗口需要 WebView2；缺失时可从 [微软官网](https://developer.microsoft.com/microsoft-edge/webview2/#download-section) 安装运行时。 |
| Python 3.10 或更新版本 | 从 [Python 官网](https://www.python.org/downloads/windows/) 安装，保留 pip 和 venv，并启用加入 PATH 的选项。 |
| Node.js 与 npm | **仅从源码构建时需要**，建议安装 [Node.js 官网](https://nodejs.org/zh-cn/download) 当前支持的 LTS 版本，npm 随附。 |
| 网络连接 | 首次安装组件、调用 API，以及读取或刷新网络提示词时需要联网。 |

Windows x64 用户可直接下载安装 `Chat-to-image-0.2.0-windows-x64-setup.exe`，无需预装 Python 或 Node；安装说明见[Windows 独立安装器](#windows-独立安装器)。以上环境要求仅适用于源码部署。

### 选择你下载的文件

| 下载方式 | 怎么使用 |
| --- | --- |
| Release 附件中的 `Chat-to-image-0.2.0-windows-x64-setup.exe`（Windows x64 推荐） | 双击安装，然后从开始菜单打开 Chat to image，无需另装 Python 或 Node。 |
| GitHub 的 `Source code (zip)`、`Code → Download ZIP` 或克隆的源码 | 完整解压或克隆后，先双击 `build-app.cmd`，构建成功后再双击 `run-app.cmd`。 |

**不要直接在压缩包内启动，也不要只复制启动脚本。** GitHub 自动生成的源码包不包含 `dist/`，首次必须先构建。若下载页只有源码，请使用源码步骤，不要将它当成已构建包。

`build-app.cmd` 会在本机缓存目录安装前端依赖并构建，再更新程序目录的 `dist/`，支持中文和网络共享路径。构建失败时保留错误提示，不需要手工修改 `dist/`。

从源码首次启动会在本机用户目录创建专用 Python 环境并安装桌面组件，请保持网络连接并等待。准备完成后打开 **Chat to image** 窗口；正常运行不保留命令行窗口，失败会显示提示。

首次功能介绍可勾选 **不再自动显示此介绍** 后点击 **开始使用**。以后可在 **设置与 API → 功能介绍** 重看；创作页顶部的 **操作指南** 提供按主题分类的帮助。

## 首次配置与第一张图片

### 1. 配置图像服务

1. 打开左下角 **设置与 API → API 配置 → 生图API配置卡**。
2. 点击 **添加 API 配置**，填写名称、服务商提供的 API 地址和 Key。
3. 点击 **获取模型**，选择图像模型并添加，设好默认模型。服务商不提供模型目录时，手动填写其给出的模型 ID。
4. 确认该配置已启用并设为主用，点击 **保存配置**。

地址按服务商说明填写，Key 只放在 Key 输入框中。**测试连通** 和 **获取模型** 只读取模型目录，不发起生图或对话；目录读取成功不等于全部模型能力可用。

### 2. 直接生成第一张图片

1. 回到 **创作**，点击顶部 **生图参数**，选择图像模型、尺寸、质量和张数。第一次可先生成一张。
2. 在底部输入框填写提示词，例如：“白色背景上的橙色纸飞机，柔和棚拍光线，简洁构图。”
3. 点击 **直接生成**。它把提示词和附件直接交给图像服务，不需要对话模型。
4. 等待右侧出现结果，点选图片后可放大、下载、收藏或继续修改。

尺寸、透明背景、格式等能力以所选模型和服务商为准。生成成功的图片保存在当前入口的历史中，重要作品建议另外下载或备份。

### 3. 开启对话式创作（可选）

在 **API 配置 → 对话API配置卡** 添加支持 **Responses** 接口的对话服务，填写地址、Key 和模型，启用并保存。对话服务和图像服务可以来自不同供应商。

回到创作页，在输入工具栏选择对话模型，输入要求后点击 **发送**。普通讨论用于交流和优化提示词；明确要求“生成一张……”或“修改这张……”时，助手可调用已配置的图像服务。

## 对话创作与图片编辑

创作页左侧显示对话，右侧按轮次比较当前分支的图片。顶部可切换 **左右分栏 / 展开对话 / 聚焦图片**；窄屏可在对话和图片之间切换，草稿保留。图像参数在顶部 **生图参数** 中调整，对话模型、推理强度和联网在输入工具栏中选择。

| 想做什么 | 操作 |
| --- | --- |
| 先讨论或整理想法 | 输入要求后点击 **发送**；需要看图时先选择支持图片理解的对话模型。 |
| 只改写提示词 | 点击 **只优化提示词**，本次只回复文字；回复下可选 **填入输入框**，修改后再提交。 |
| 按现成文字生图 | 点击 **直接生成**，或在回复下点击 **按此提示词生图**；直接提交文字，不经过对话优化。 |
| 使用参考图 | 上传、拖入、粘贴图片，或从结果、历史、提示词详情引用图片；可用 `@` 指定图片，并说明每张图的用途。 |
| 连续修改 | 点选结果图，点击 **继续修改**，再描述需要修改和保留的内容。 |
| 修改局部 | 点选图片，打开 **蒙版编辑**，标记编辑区域并保存，再输入修改要求后提交。 |
| 调整输出效果 | 打开 **生图参数**，按接口支持情况调整尺寸、质量、格式、透明背景和张数。 |
| 停止任务 | 点击 **停止**，已完成的图片保留；停止本地处理不保证服务商撤销已受理的请求。 |

例如：“只把外套改成红色，保留脸、姿势、面料和背景”，或“图一参考人物，图二只参考画风”。图片引用本身不会自动生成，提交时才会按请求发送附件。

**绘图提示词优化** 位于 **设置与 API → 习惯配置 → 对话习惯**，默认开启，帮助对话助手整理修改范围、参考图用途和需保留的内容。它与图像生成设置中的 **允许模型优化提示词** 分别控制对话助手和图像服务的行为，效果取决于模型能力。

连续工具调用上限默认为 **1**，生图后不自动迭代；可在 **对话习惯 → 高级偏好** 调整。联网、看图、工具调用和推理强度需要对话服务支持；未确认看图能力时，图片引用不代表已将图片内容传给对话模型。

输入区上方的 **当前上下文** 可查看当前分支的历史轮次和可引用图片。选图后点击 **携带图片新开对话**，只携带所选图片、图像参数和对话偏好，旧聊天文字、提示词及蒙版不会自动带入。该操作不调用 API，旧对话与草稿保留。

## 模型与备用服务

图像和对话两组各最多保存 **10 套配置**，停用的配置也计数。两组分别管理主用、启停、备用顺序及 **自动切换备用**；调整后点击 **保存配置**，取消会放弃本次全部未保存的配置修改。

获取模型后可搜索、添加所选、设为默认或移除；获取失败保留原选择。图像参数限制可在生图配置中按服务商说明填写，包括尺寸、质量、格式、透明背景和参考图上限，留空时使用通用规则。

| 情况 | 自动切换开启时的行为 |
| --- | --- |
| 主用成功 | 保存结果，记录实际使用的方案和模型。 |
| 主用缺少必要配置，或接口明确拒绝受理 | 按顺序尝试可用备用。 |
| 超时、断线、服务器错误或结果状态不明 | 停止当前请求，不自动重复提交。 |
| 成功响应开始后解析、下载或保存失败 | 不切换重发，避免重复提交同一生图请求。 |
| 批量生成中部分失败 | 保留已经保存的图片，显示失败原因。 |

图像模型选择 **自动** 时使用方案默认模型；明确选择模型后，备用只尝试已启用相同模型 ID 的方案。流式、代理及特殊图像方案标为独立使用时，不参与同步 Images 主备；Responses 的文字流式可参与对话主备。

图像服务保留 5 分钟失败冷却，可在 **最近调用结果** 查看或清除；修改连接配置也会清除旧冷却。对话服务每次按自己的备用顺序尝试。同步图像批次最多同时执行两张，完成一张保存一张；保存失败会停止后续投递。

## 提示词库

### 个人提示词与分类

左侧 **提示词库 → 个人提示词** 提供新建、搜索、编辑、收藏、删除与撤销。可点击 **保存当前草稿** 或 **新建提示词**，填写名称和正文并选择分类。

内置 45 条图文示例，包含图像创作、漫画及 AI 形象素材。示例内容以详情为准，部分条目主要用于参考图片。首次打开会加入默认示例；升级只追加尚未接收的新批次，保留已有个人内容和修改，已删除的旧批次条目不会自动恢复。

| 详情页按钮 | 对当前草稿的影响 |
| --- | --- |
| 引用提示词 | 替换文字，保留已有参考图和参数。 |
| 引用图片 | 追加预览图作为参考图，保留原文字。 |
| 引用提示词和图片 | 同时替换文字并追加预览图。 |

三种操作都不会自动生成，成功后提供撤销；继续编辑或切换对话后不再恢复旧草稿。没有预览图时不能引用图片，图片读取失败时保留原草稿。只引用提示词不会上传展示图。

点击左侧 **管理分类** 可创建、重命名或删除主题分类，至少保留一个分类。拖动分类可排序，也可聚焦后按 **Alt + ↑ / ↓** 调整，顺序自动保存。删除分类时，条目转入确认框显示的剩余分类，不会连同提示词一起删除。

| 来源 | 内容 |

| [YouMind](https://youmind.com/zh-CN/nano-banana-pro-prompts) | Nano Banana Pro 专题。 |

选择网站和分类后可搜索、翻页、查看完整提示词及大图，再引用到草稿。变量占位请按需要修改；标为需要参考图的内容应先添加参考图。点击 **收藏** 可将正文和来源保存到个人提示词，重复点击不会重复保存。

目录首次读取后缓存，重开优先复用；需要新内容时点击 **刷新**，刷新失败保留已有目录。可 **预载当前分类** 或在全部分类中 **预载全部** 图片，支持进度、取消和再次补齐。预载范围不受当前页及搜索结果限制，已保存图片会跳过。

**清除预载数据** 会清除当前网站全部分类的目录、正文和预览图，保留个人收藏。**删除提示词库** 还会移除网站入口；可在 **已删除的库** 中恢复入口，再刷新获取内容，旧缓存不会随恢复入口自动找回。操作前请核对确认框。

网络来源和图床可能变化，刷新或预载失败时可稍后重试。图片预载需要桌面或本地浏览器入口，独立静态网页可能受跨域限制。目前不支持输入任意网址自动建立网络库。

### 自定义保存位置

进入 **设置与 API → 数据管理 → 提示词库保存位置**，选择文件夹或填写完整路径，点击 **复制并使用新位置**，立即生效。应用在所选位置下创建独立的 `提示词库` 子目录，保存个人提示词、网络目录、分类、来源及已有预载图片。

更换位置先复制校验，成功后才切换；非空目标不覆盖，默认保留旧数据。已有文件目录再次迁移时，可勾选 **迁移成功后清理原位置文件**，确认新旧位置后，只清理应用登记的文件，优先移入回收站。清理失败不影响新位置使用，界面会提示残留。

迁移不会自动下载未预载图片。多个窗口同时修改时请先停止其他窗口的操作，收到旧窗口提示后重新打开。目录暂时不可访问时，恢复访问后重开工具，不会自动用旧缓存覆盖目录。

同一本机部署的桌面与本地浏览器可读取同一提示词目录，文件模式不提供多设备并发同步。文件由应用维护，手动修改分类文件不会反向导入。完整备份方法见下一节。

## 历史与收藏

右侧底部 **最近生成** 显示最近任务，顶部入口可打开完整历史。可预览、下载、收藏、加入参考图、复用提示词与参数或删除。复用只填入草稿，使用当前图像配置，不会自动提交；**打开原对话** 才会切换回旧对话。

创作页顶部 **对话历史** 可搜索、改名、删除和批量管理；**多选 → 全选** 只选择当前搜索结果。默认删除对话保留作品，勾选 **同时删除关联任务和图片** 才一并删除。正在生成或回复的对话会被跳过并提示。

生成历史每页 60 条，搜索和筛选覆盖全部历史；跨页选择保留，删除前检查已选数量。生成中的任务需先停止。**我的收藏** 支持收藏夹管理，每个收藏夹展示最近加入的四张不同图片。

## 数据保存与备份

### 数据保存在哪里

| 数据 | 保存方式 |
| --- | --- |
| API、模型、主备与使用习惯 | 程序目录的 `user-config/`，Key 使用当前 Windows 用户的 DPAPI 加密。 |
| 桌面作品、历史与对话 | 本机用户数据区中的桌面 WebView 存储。 |
| 本地浏览器作品、历史与对话 | 当前浏览器的站点存储，与桌面分别保存。 |
| 提示词与预载图片 | 默认在当前入口存储；启用自定义目录后保存到所选目录。 |
| CLI 生成结果 | 默认在本机用户数据区，也可指定输出位置；不自动加入桌面历史。 |
| 手动备份 | 保存在你选择的下载位置，独立于程序目录。 |

桌面、本地浏览器和 CLI 共用 API 设置，**不代表共用全部作品和对话**。设置需点击保存，其他已打开入口通常约 5 秒内更新。同一份设置被另一窗口修改后，旧草稿会拒绝保存，请重新打开设置后再编辑。

### 导出与恢复

1. 完成或停止当前生图和对话任务，打开 **设置与 API → 数据管理**。
2. 勾选需要的范围：**包含配置**、**包含作品、对话和个人提示词**。
3. 点击 **导出所选数据**。较大的备份会自动分片，请允许下载多个文件，并在下载目录确认全部 ZIP 都已保存。
4. 恢复时选择需要导入的范围，点击 **从 ZIP 导入所选数据**；分片备份应一次选中同一批次的全部分片。

**勾选“包含配置”导出的 ZIP 会包含 API Key 等配置，且未加密，请勿上传 GitHub 或公开分享。** 分享作品前应取消包含配置，并检查所选作品、对话及个人提示词是否适合分享。

作品备份包含个人提示词正文、分类和链接，**不包含全部网络提示词目录和预载图片**。要备份完整文件库，请先停止提示词相关操作，再复制整个自定义 `提示词库` 文件夹。仅保留图片链接不能保证以后离线可看。

**存储与备份状态** 显示当前入口、站点空间估算和最近发起备份下载的记录；估算不包含所有本机文件，发起下载也不等于文件已经落盘。清理浏览器数据、卸载或移动程序前，请先检查备份可用。

若出现 **重试保存对话**，内容仍保留在当前窗口，应先重试成功再关闭。强制结束程序可能丢失未保存的末尾内容，本地保存失败不会自动再发起生图请求。

## 更新与换电脑

### 在原电脑更新

1. 先导出重要作品、对话和个人提示词，使用自定义提示词目录的再单独备份该目录。
2. 停止任务并关闭桌面；本地浏览器服务仍运行时，也先停止该服务。
3. 将新版本程序文件更新到原位置，保留自己的 `user-config/` 和独立存放的备份。不要删除本机用户数据目录。
4. 使用源码更新时，重新运行 `build-app.cmd`；使用带 `dist/` 的完整包时，按该版发布说明操作。
5. 重新打开 `run-app.cmd`，检查配置、历史和提示词；外部 Agent 接入可在 **Agent 连接** 中更新。

移动程序目录不会自动搬运作品和历史，建议更新时沿用原位置。已有加密配置无法读取时，不要反复覆盖原文件。

### 换电脑或 Windows 账户

1. 从原入口导出需要迁移的数据，备份文件自行妥善保管。复制程序时跳过 `user-config/`、个人输出及私人备份。
2. 新电脑准备 Python、WebView2 和完整程序文件，源码需先构建。
3. 重新填写 API 地址、Key 和模型，再按需要导入作品备份、迁移提示词库。
4. 在新电脑重新连接外部 Agent。移动项目前可在旧位置断开，移动后重新连接，更新调用路径。

旧账户的加密文件不能保证在新环境解密。若启动提示无法读取配置，可返回原电脑与账户使用，或点击 **保留旧配置并重新配置**：原配置保留为备份，新配置需重新填写 Key，不会清空历史和作品。项目文件同步不等于跨设备数据同步。

使用过旧 Qt 版本的用户，其原生作品库仍保留在原位置，不会自动迁入当前桌面或被删除。

## 本地浏览器与外部 Agent

### 本地浏览器

已有 `dist/` 后双击 `run-sync.cmd`，它启动或复用本机服务并打开浏览器。该服务的生命周期独立于桌面窗口，关闭浏览器标签页不等于停止服务。

若希望保留控制台方便停服，在程序目录运行：

```powershell
.\run-sync.cmd --stay-open
```

按 Ctrl+C 停止该入口创建的服务和任务，复用的服务及独立 CLI 调用不受影响。独立部署的静态网页使用自己的浏览器设置，三端共用 API 配置请使用本工具提供的本地入口。

### 外部 Agent 与命令行

打开桌面 **设置与 API → Agent 连接**，选择 Codex、Claude Code、Cursor 或 DeepSeek Harness，执行连接。重新打开对应 Agent 会话，让它读取接入文件；连接就绪只代表接入文件已准备，不代表模型或服务商已实际验证。

可在程序目录运行以下只读检查：

```powershell
.\chat-to-image.cmd doctor
.\chat-to-image.cmd agent-guide
.\chat-to-image.cmd agents status
```

`doctor` 检查本机环境和脱敏配置，不联网验证 Key。CLI 读取共享图像配置，桌面关闭后仍可独立使用；生成与编辑命令、输出位置及 DeepSeek Harness 的自定义目录说明见 [CLI 接口文档](docs/codex-image-interface.md)。当前提供本地 CLI 接入，没有注册 MCP 服务。

关闭桌面只停止其创建的服务与任务，不停止独立 CLI 调用。移动程序或更换电脑后，应重新连接 Agent 或重新复制连接页生成的本机调用命令。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 双击后提示没有 Python | 安装 Python 3.10+，确认启用了加入 PATH，并保留 pip、venv；重新打开后再试。 |
| 提示缺少页面或构建文件 | 检查是否下载了源码包。先安装 Node.js/npm，再运行 `build-app.cmd`，成功后启动。 |
| 首次准备组件失败 | 根据错误提示检查 Python、网络和文件夹权限；缺少 WebView2 时安装其运行时后重试。 |
| 只有图像 Key，无法聊天 | 可以使用 **直接生成**；文字聊天需要另配 Responses 对话服务。 |
| 获取模型成功，但生成失败 | 核对所选模型、账户额度、接口类型及尺寸等参数。模型目录可读不代表拥有生成权限或全部能力。 |
| 修改设置后没有生效 | 点击 **保存配置** 并确认成功；其他窗口同时修改时重新打开设置。已提交的任务仍使用提交时配置。 |
| 原配置无法解密 | 回原电脑与账户使用，或按启动页提示保留旧配置并重新填写。 |
| 超时、断线或关闭窗口后结果不确定 | 先查看服务商记录，再决定是否重试；停止本地任务不保证远端取消或退款。 |
| 网络提示词或图片加载失败 | 检查网络，稍后刷新或继续预载；来源网站变化时可能需要更新程序。 |
| 对话或流式请求提示跨域错误 | 服务商需要允许页面跨域请求；标准桌面同步 Images 请求通过本机服务发送。 |
| 换浏览器或入口后看不到历史 | 桌面和各浏览器的历史分别保存，请回原入口导出，再到目标入口导入。 |
| 备份提示成功但缺文件 | 检查下载目录，允许多个文件下载，核对同批次分片是否齐全；页面记录只表示已发起下载。 |
| 提示重复启动或端口占用 | 先从任务栏找已有窗口；若端口由其他程序占用，确认归属后处理，不要随意结束其他程序。 |

真实服务商的看图、联网、推理、透明背景和编辑能力应以实际调用为准。不同电脑、屏幕缩放和网络盘环境仍可能存在差异。遇到问题可在 [GitHub Issues](https://github.com/Kenrohoro-hub/Chat-to-image/issues) 提供复现步骤、版本和已遮盖敏感信息的错误截图，不要附带 Key 或完整配置备份。

## 内置示例与发布包

本项目自带的 **45 条默认提示词及其 45 张展示图**属于项目资源，不属于用户个人资料，可随项目发布和打包。它们显示在“个人提示词”入口，不改变其项目资源归属。

源码包保留 `src/lib/promptExamples.ts`、它引用的示例数据模块与 `public/prompt-examples/`；带构建文件的包还需保留完整 `dist/`，包括 `dist/prompt-examples/`。发布时排除 `user-config/`、个人作品、个人提示词修改、备份、运行日志和临时输出，不要直接压缩自己的整个工作目录。

## Windows 独立安装器

当前版本安装文件为 `Chat-to-image-0.2.0-windows-x64-setup.exe`，适用于 Windows 10（1809 起）和 Windows 11 x64。双击安装后，从开始菜单打开 **Chat to image**；可在安装时勾选桌面快捷方式。内置 Python、桌面组件、构建页面及 WebView2 离线安装包，电脑无需预装 Python 或 Node，安装过程无需联网下载组件。首次填写自己的 API 后才能调用模型服务。

安装默认为当前用户的应用程序目录；配置仍保存在安装目录的 `user-config/`，历史与作品沿用本机用户数据区。安装包只收集程序白名单和重新构建的 `dist/`，不收集个人配置、作品、提示词目录、日志、Agent 接入记录或备份；45 条默认提示词及其展示图正常保留。升级安装到原目录可保留已有数据；卸载只移除安装文件和快捷方式，保留 `user-config/` 及用户数据区。迁移数据仍使用应用导出/导入功能。

安装目录的 `chat-to-image.cmd`、`run-image.cmd`、`run-sync.cmd` 均优先使用内置 Python。外部 Agent 可从 **设置与 API → Agent 连接** 建立连接；卸载前可在该页断开，避免留下指向已卸载程序的调用命令。旧源码部署的数据不会自动迁入安装版，需先在旧入口导出。

### 维护者重新打包

在已安装 Python、Node/npm、PowerShell 7 和 Inno Setup 6 的 Windows x64 电脑，运行项目根 `build-installer.cmd`。脚本重建前端，下载官方 Python 嵌入包和微软 WebView2 离线组件，锁定桌面依赖；Python 包校验 SHA-256，WebView2 验证微软数字签名。最终文件位于 `release/`，上传 GitHub Release 时使用 EXE、同名 `.sha256` 和 `Chat-to-image-signing.cer` 公钥证书。`package-files.txt` 是包内程序文件清单，供排查资源使用。

每次打包都会重新构建前端，避免旧 dist 中混入手工添加的文件；完整发布前仍需运行前端测试。可用 `--iscc` 指定编译器，`--cache` 指定本机下载缓存。不要手工把整个项目目录压进安装器。构建缓存与安装器均不纳入 Git。


### 安装器与卸载程序自签名

`build-installer.cmd` 自动为安装器、安装过程使用的临时程序及卸载程序签名。首次打包在当前 Windows 用户的个人证书库创建 `Chat to image` 专用代码签名证书，RSA 3072 位、SHA-256，有效期三年，私钥不可导出；以后打包复用同一证书。私钥不进入项目、安装包或 Git。签名或校验失败会中止构建，SHA-256 文件在最终签名后生成。

`release/Chat-to-image-signing.cer` 仅含公钥，可与安装器一起提供。构建不会自动把它加入受信任根或发布者证书库。自签名能用于核对文件来源及完整性，但其他电脑不会因此自动信任发布者，也不保证消除 SmartScreen 提示。Windows PowerShell 可能将“证书根未受信任”显示为 `UnknownError`；构建会核对签名者并用 Windows 原生校验精确区分此状态与文件被修改。只信任自己确认过来源和指纹的证书。

证书绑定当前 Windows 用户和电脑。换电脑或重装系统后需要新的签名证书；现有证书过期时构建会提示处理，不会静默更换身份。当前自签名不带外部时间戳，证书到期后需用有效证书重新签署。已发布的 GitHub 附件不会因本地重新打包自动更新。
