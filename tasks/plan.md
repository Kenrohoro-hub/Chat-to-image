## 本版更新：图片交互与对话张数

- 点击生成结果直接打开高清原图，支持左右按钮和键盘方向键切换当前分支图片；同步选中该图供继续修改、下载等操作使用，已移除独立“放大图片”按钮。
- 最近生成的缩略条和展开列表均支持拖入对话框；展开列表拖动当前选择的图片。
- 已移除连续工具调用上限的界面、设置和执行限制，旧配置不再生效。未指定张数时沿用生图参数；本次聊天明确指定张数时通过图像工具的 n 参数覆盖，仅影响本次任务，不改变对话默认参数。不同提示词按本次要求分配张数，单次工具参数最多 16 张，更多图片可拆分调用。
- 继续保留手动停止、重复调用去重、断线恢复及已生成结果保存。源码、本地构建、中英文使用说明及 Windows 安装器已同步至 v0.4.0。

## 本版更新：手动检查更新

- 用户已确认手动检查 GitHub 正式版，确认后下载安装。在“设置与 API → 检查更新”查看版本、更新说明和下载进度；安装版桌面校验安装器后提供“退出并安装”，沿用原安装目录。
- 下载只接受本项目对应版本的 Windows x64 安装器及校验附件；核对大小与 SHA-256，安装前再次校验，失败可重试。未保存设置、运行任务及未启用恢复的输入草稿会阻止退出升级；退出前等待设置和对话保存。
- 本机网页和源码运行支持检查及发布页入口，安装版可下载安装。v0.3.0 及更早版本没有此入口，升级到 v0.4.0 需先从发布页下载安装器并覆盖到原目录；四份中英文说明已同步该区别。
